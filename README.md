# 模拟手机（角色资料版）

这是从 `chami_tavern-scene-plugin` 中独立剥离出的 SillyTavern 模拟手机插件。仓库运行时只加载模拟手机，不加载标签超市、角色数据库、绘图、AI 后处理或其他酒馆场景功能。

## 保留的完整手机功能

- 手机悬浮球、主页、消息与联系人
- 朋友圈、论坛、新朋友、语音与转账
- 音乐、地图、小说、重开人生、保活
- 剧情百科、直播、五子棋、云宠物
- 手机 API、服务器、表情与内容过滤设置
- 新增“角色资料”应用
- 新增“校园小帮手”独立世界书页面（不嵌在手机框内）

模拟手机主控制器和原有 `Phone_emulator` 目录保持完整，所有原手机子应用继续由同一主控制器初始化。

## 角色资料

角色资料由两层组成：

- 固定资料：直接读取用户选定的世界书角色条目，只读，不修改原条目。
- 动态资料：根据聊天上下文创建和增量更新，并写入独立世界书条目。

动态条目支持自定义前缀和命名模板，并使用稳定的隐藏 `TSP_PROFILE_ID` 识别，所以修改名称后仍可继续更新。

角色资料依赖酒馆助手的世界书宏和 `generateRaw()`。未安装酒馆助手时，原模拟手机其他功能仍可使用。

## 校园小帮手（独立页面）

加载插件后，酒馆扩展菜单会出现“校园小帮手”。它以独立全屏页面打开，手机端会自动适配为全屏布局与底部抽屉保存面板，桌面端则显示为右侧独立面板。

功能包括：切换“角色模板”与当前角色主世界书、直接启用或禁用条目、发送角色生成指令，以及从最新回复的 `<all_char>` 和 `<key_words>` 自动读取内容后写入主世界书。保存时默认使用绿灯、指定深度 6、顺序 100。此页面和角色资料一样依赖酒馆助手的世界书宏。

## 与原酒馆场景插件同时使用

原酒馆场景插件请从上游仓库单独安装：

```text
https://github.com/shaochami/chami_tavern-scene-plugin
```

上游插件自身也包含一个模拟手机模块。为了避免出现两个手机悬浮球，请在原酒馆场景插件设置中关闭“手机模拟器”，然后保留本独立插件的手机功能。

独立插件还会检测页面上是否已经存在 `.tsp-phone-fab`；检测到其他手机实例时不会重复初始化，并会提示关闭原插件中的手机模块。

## 安装

仓库重命名完成后，在 SillyTavern 的“安装扩展”中粘贴：

```text
https://github.com/guanyuzhao96-cmd/chami-phone-emulator
```

最低 SillyTavern 版本：`1.14.0`。

## 仓库结构

```text
Phone_emulator/                 完整模拟手机源码与资源
core/                           手机所需的最小兼容适配层
phone-plugin.js                 独立插件入口
styles/phone-plugin.css         独立样式入口
manifest.json                   SillyTavern 插件清单
CHARACTER_PROFILE.md            角色资料模块说明
```

## 来源与改动

原模拟手机代码来源于茶蘼与 Tavern Scene Team 的酒馆场景插件；本仓库仅负责将手机模块独立化，并加入角色资料模块。请遵守原项目的授权、署名和分发要求。
